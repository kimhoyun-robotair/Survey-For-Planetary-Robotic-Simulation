# Survey companion design

The page is an English academic reference, optimized for reading and finding evidence.

- Colors: warm paper `#faf9f5`, ink `#202e30`, muted text `#586567`, forest accent `#285b4e`.
- Typography: system Arial/Helvetica for body text and controls; Georgia for paper and section titles. No external font requests.
- Layout: 1180px maximum content width, 32px desktop gutters, 20px mobile gutters.
- Components: section introductions, dataset statistics, filter controls, native expandable records, source links, verification register.
- Responsive behavior: two-column content becomes a single column below 680px; record summaries reflow into labeled content; the check table scrolls inside its own region.
- Accessibility: semantic landmarks, a skip link, visible focus, named form controls, native keyboard-operable disclosures, live filter results, and reduced-motion support.
- Content: the paper dataset and companion additions remain distinct. Current link responses never overwrite paper classifications.

The site uses static HTML, CSS, and progressive JavaScript enhancement. All records and source links remain accessible without JavaScript.
